# USB_safely — U盘锁

> U盘锁·电脑防护程序：保护 U 盘里的个人文件，防止别人翻看。
> 设计来源：JAC 初中时期手写设计方案（v1 草案 + v2.0），由 Geek-Hub 实现初版。
> 完整设计规格见 [DESIGN.md](DESIGN.md)。

## 这是什么？

把 `USB_safely` 放进 U 盘，插到电脑上运行锁定程序后，**U 盘入口被锁定界面挡住**，必须输入你预设的密码才能访问里面的个人文件（电脑本身不受影响）。

## 当前版本：v0.1.0 初版

### ✅ 已实现

| 功能 | 说明 |
|---|---|
| 全屏锁定界面 | 置顶无边框，显示在所有程序上层，深色主题 |
| 自带屏幕键盘 | A-Z、0-9、`*` `-` `#` 共 39 键 + 退格（v2.0 设计稿中的"38 键"实际为 39 键） |
| 快捷键屏蔽 | Win 键、Alt+Tab、Alt+F4、Win+R/Esc 组合等全部拦截（Ctrl+Alt+Del 为系统安全序列，任何程序无法屏蔽） |
| 密码安全存储 | U 盘根目录 `password\pw.sf`，只存 SHA256 哈希，不存明文 |
| 首次使用引导 | 未检测到密码文件时自动进入设置模式 |
| 错误惩罚 | 连续输错 5 次 → 锁定 60 秒倒计时 |
| 取消并弹出 | 「⏏ 取消并弹出U盘」按钮：安全弹出 USB 设备并退出 |
| 设置模式 | 修改密码（旧密码验证）、关于程序、版本号连点 5 下开启超级模式（手稿彩蛋） |

### 🗺️ 后续路线（对应 v2.0 设计稿，详见 DESIGN.md）

- **解锁模式分级**：无需解锁 / 普通（数字）/ 加密（字母）/ 进阶（混合）/ 密钥模式（最长 500 位，任意字符含 emoji 皆可输入）
- **递进式输错惩罚**：错 3 次→锁 60 秒；错 5 次→清除密码数据；极端→强制关机（可设置里关闭）
- **后台待命**：解锁后程序缩到托盘，可一键重新锁定，U 盘拔出自动退出
- **超级模式完整实现**：忘记密码试错恢复 + 卸载保护
- **忘记密码定时清除**：24 小时 / 1 月 / 1 年
- **文件加密保险箱**：AES 加密个人文件夹（技术兜底，防止高手绕过锁直接翻盘）

## 使用方法

```
U盘
 ├─ USBsafely.exe     主程序（双击=启动锁屏）
 ├─ run.bat           启动锁定
 ├─ Lock.bat          同 run.bat
 ├─ setup.bat         设置模式（改密码）
 ├─ intro.bat         使用说明
 ├─ clean.bat         清除密码文件（慎用）
 ├─ Close.bat         关闭锁屏
 ├─ Stoprun.bat       同 Close.bat
 └─ autorun.inf       (Win7+ 已禁用自动运行，保留作纪念)
```

> ⚠️ Windows 7 起 U 盘自动运行（autorun.inf）已被系统禁用，插入 U 盘后请**双击 run.bat** 或 `USBsafely.exe` 启动锁屏。

1. 把上面的文件复制到 U 盘**根目录**
2. 双击 `setup.bat` → 设置锁屏密码（存入 `password\pw.sf`）
3. 要锁电脑时双击 `run.bat`，输对密码解锁；点「取消并弹出U盘」会安全弹出 U 盘

## 从源码构建

程序为纯 Win32 API C 语言实现（无任何第三方库，符合设计稿"最小方案"）：

```bash
x86_64-w64-mingw32-gcc src/main.c -o USBsafely.exe -municode -mwindows -O2 \
    -luser32 -lgdi32 -lbcrypt -lcfgmgr32 -lshell32 -ladvapi32
```

也可用 Windows 上的 MinGW-w64 / MSYS2 直接编译。
